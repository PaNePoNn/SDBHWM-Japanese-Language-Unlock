SDBHWM Japanese Language Patch (Steam)
======================================

Enables Japanese text and furigana in SUPER DRAGON BALL HEROES WORLD MISSION.
Also sets up an offline launcher that does not load EAC.

INSTALL
1. Exit the game and extract the ZIP.
2. Run 01_Install_Japanese_Offline.cmd.
3. Remove any old JP_Mode_Steam.ps1 Steam launch option.
4. Launch the game using Steam's Play button.

An internet connection is required on first install.
If the game is not detected, select SDBHeroes_WorldMission.exe.

RESTORE
Run 02_Restore_Original.cmd.
For a status check, run 03_Check_Status.cmd.

NOTES
- For supported Steam builds on Windows 10/11.
- Online play is not recommended; compatibility with official EAC is not guaranteed.
- No game files or Steamless are included; required tools are downloaded automatically.
- Original files are backed up automatically.
- Unofficial mod; not affiliated with the game's rights holders.
