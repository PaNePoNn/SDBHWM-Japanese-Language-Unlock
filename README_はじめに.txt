SDBHWM 日本語化パッチ（Steam版）
=================================

SUPER DRAGON BALL HEROES WORLD MISSION の日本語表示とふりがなを有効にします。
EACを読み込まないオフライン用起動方法も設定します。

【インストール】
1. ゲームを終了し、ZIPを展開する。
2. 01_Install_Japanese_Offline.cmd を実行する。
3. Steamの起動オプションに「JP_Mode_Steam.ps1」が残っていたら削除する。
4. Steamの「プレイ」から起動する。

※初回のインストールにはインターネット接続が必要です。
※ゲームの場所が見つからない場合は、ゲーム本体のEXEを選んでください。

【元に戻す】
02_Restore_Original.cmd を実行する。
状態の確認は 03_Check_Status.cmd からできます。

【注意】
・対応するSteam版／Windows 10・11向けです。
・オンラインプレイは非推奨です（正規EACとの互換性は保証されません）。
・ゲーム本体やSteamlessは同梱していません。必要なツールは自動取得します。
・元のファイルは自動でバックアップします。
・非公式MODです。各権利者とは関係ありません。
